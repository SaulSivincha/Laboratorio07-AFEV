# Laboratorio 07 — AFEV

Transcripción de todos los bloques de especificación, comandos de prueba y salidas de intérprete que aparecen en el informe del laboratorio de validación mediante análisis de cobertura.

- `ejercicios-resueltos/`: clase `Monedero`, dos suites, refinamiento y sus resultados.
- `ejercicios-propuestos/`: pruebas del ejercicio 1, especificación `Inventario`, pruebas y resultados.

Los comandos de prueba se ejecutan en el intérprete de VDMTools. Los archivos `*.txt` conservan la transcripción de los bloques mostrados en el PDF; las líneas de resultados no son código ejecutable.
