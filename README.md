# Laboratorio 07 — AFEV

Especificaciones y casos de prueba en VDM++ para el laboratorio de validación mediante análisis de cobertura.

- `ejercicios-resueltos/`: clase `Monedero` y sus suites de prueba.
- `ejercicios-propuestos/`: clase `Inventario` y pruebas de cobertura.

Los comandos de prueba se ejecutan en el intérprete de VDMTools.
